Hit-or-Myth: Emotion, Audio, and Popularity in Spotify Tracks

Jun 2026 · DSC 80, UC San Diego · Team project with Kitty Ming

  • Investigated whether happier songs are more popular, using a subset of 5,000 tracks across five genres from a 114,000-track Spotify dataset.
  • Cleaned the data and assessed missingness in tempo (about 20% missing), using permutation tests to show it depends on energy but not duration.
  • Ran a permutation test finding no significant link between valence and popularity (r ≈ 0.009, p ≈ 0.52).
  • Built a Random Forest model with engineered features and tuned it with grid search, lowering RMSE from 32.38 to 23.50 and raising R² from 0.04 to 0.50.
  • Ran a fairness analysis comparing model error on classical vs. non-classical songs.
  • Published the full analysis as a Jekyll and GitHub Pages site with interactive Plotly charts. View project
